# DATA SCIENCE PROJECTS

## 📌 About

This repository contains a collection of Machine Learning and Deep Learning projects developed using Python, Flask, TensorFlow, Scikit-learn, and other AI technologies.

These projects demonstrate predictive analytics, classification, forecasting, and intelligent decision-making using real-world datasets.

---

## 🚀 Projects Included

### 1. Demand Forecasting
**Description:**
A Machine Learning project that predicts future product demand using historical retail sales data.

**Technologies:**
- Python
- Flask
- Scikit-learn
- Random Forest
- Pandas
- NumPy

---

### 2. Equipment Health Monitoring
**Description:**
An AI-based predictive maintenance system that monitors equipment health and predicts possible failures.

**Technologies:**
- Python
- Machine Learning
- Random Forest
- Flask
- Pandas

---

### 3. Fruits Classification
**Description:**

**Technologies:**

- Flask

### 4. Food Safety Classification
